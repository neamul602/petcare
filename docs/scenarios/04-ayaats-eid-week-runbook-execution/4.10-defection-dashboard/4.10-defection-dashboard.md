# 4.10 — Off-Platform Defection Detection Dashboard

## Overview

**Page Purpose:** Ayaat sees soft signals that owners/providers are moving the next booking to WhatsApp — before the moat starts dissolving. The shared cross-group driver's signal surface.

**Exit Action:** Tap a pattern → intervention playbook (FR-36 re-engagement flow + FR-48 on-platform repeat value).

## Page Composition

### Defection soft-signal categories
- **Owner-side signals:**
  - Repeat-booking rate drop (SM-2 trend)
  - Care-history viewed but no booking submitted
  - Owner unbookmarked / unsaved
  - "I'm booking again" search returning zero results
- **Provider-side signals:**
  - Provider utilization drop (SM-13 trend)
  - Provider accepted fewer bookings in last 30 days
  - Provider's profile views but no conversions
- **Cross-side signals:**
  - Owner + provider pair appeared together once but no second booking

### Pattern detection
- "12 owners with care-history ≥ 1 booking have not re-booked in 60+ days" · intervention CTA

### Intervention playbook
- Owner re-engagement nudge ("Your pet's care history is here — book in under 4 min")
- Provider re-engagement offer (during off-peak trough)
- Both flow through PetCare, not WhatsApp

## State Variations

- **No-patterns**: Clean state
- **Patterns-detected**: Inline cards with intervention suggestions
- **High-attrition-period**: Banner "Repeat-booking rate trending down 8% · investigate"
