# 4.7 — Review Moderation Queue

## Overview

**Page Purpose:** Ayaat moderates reviews for cause (abuse, off-topic content) — does NOT optimize for average star rating (SM-C3 counter-metric).

**Exit Action:** Approve / Edit / Remove review.

## Page Composition

### Review card
- Reviewer name · booking ref · rating · text · photos
- Automated flags (profanity, off-topic, low-effort)
- Ayaat's decision history for similar reviews (consistency check)

### Actions
- **Approve** (publishes to provider profile)
- **Edit** (redact specific content · keeps the rest)
- **Remove** (with reason required)

## State Variations

- **High-volume-period**: Bulk-view for similar patterns
- **Edge-case-review**: Escalate to Ayaat's manual review only

## What This Page Must NOT Do

- No star-rating-only optimization (SM-C3 explicit counter-metric)
- No removing reviews just because they're critical — only for cause
