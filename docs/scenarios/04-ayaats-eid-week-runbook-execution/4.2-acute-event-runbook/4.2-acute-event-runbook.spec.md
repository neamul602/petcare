# 4.2 · Spec — Acute Event Runbook View

> **THE R-10 LAUNCH-BLOCKING SURFACE.** Pre-built escalation path for any acute event during a stay — trigger confirmation, role split, notification cadence, vet-clinic lookup, payout implications, post-mortem entry. **SM-20: first timeline entry within 5 minutes of trigger.**

## URL & Routing

- **Route:** `/admin/runbook/:eventId` · deep-linkable from queue dashboard and from SMS/push notifications
- **Auth gate:** `admin` role required
- **Polling:** every 30s for status changes · push subscription on `runbook.{id}` channel
- **Mobile:** secondary — push notification opens this page on phone when Ayaat is away from desk

## Design Sections

**D1. Header** — back to queue · event ID · pet + event-type subtitle

**D2. Alert banner** — `{destructive-soft}` · event metadata · live elapsed timer · green check at <5min

**D3. Runbook steps** — `{card.elevated}` · 7-step predefined sequence
- ✓ Done steps (forest-green check + timestamp)
- ▶ Active step (forest-green arrow + "active now")
- ○ Pending steps (muted circle + "pending")
- Each step expandable for context

**D4. Owner-notification template** — `{card.muted}` · pre-built copy · language toggle · send buttons

**D5. Timeline (chronological)** — `{card.muted}` · icon per entry type · live input at bottom

**D6. Helper line** — `text-sm text-muted-foreground` · "Aim: first timeline entry within 5 min · post-mortem within 48 hr"

## On-Page State Machine

- **State 1 (trigger-just-fired — current):** Step 1 done · Step 3 (Admin) active · timeline empty · banner shows 5min timer
- **State 2 (in-resolution):** Steps 1-5 done · Step 6 (payout implications) active · timeline populated · follow-up cadence active
- **State 3 (post-mortem-due):** All steps complete · resolution documented · banner "Post-mortem due within 48 hours" · CTA routes to 4.9
- **State 4 (acute-event-resolved):** All steps done · banner `{success-soft}` · auto-link to 4.9 post-mortem log
- **State 5 (timeline-entry-saved):** Live entry added · optimistic UI · entry appears at top · count badge updates

## Accessibility

- Alert banner: `role="alert" aria-live="assertive"` · announces event metadata
- Elapsed timer: `role="timer" aria-live="off"` · `aria-label="5 minutes elapsed, on target"`
- Runbook steps: `<ol>` semantic · each step `<li>` with `aria-current="step"` on active
- Vet-clinic lookup: `aria-label="Gulshan Veterinary, 1.2 kilometers, open until midnight"`
- Notification template: `<textarea readonly>` · copy-to-clipboard button
- Language toggle: `role="radiogroup"` · EN/BN exclusive selection
- Timeline: `<ol>` semantic · entries chronologically ordered · live region announces new entries
- Send buttons: `aria-label="Send notification to Bibi via PetCare"` · full context
- All CTAs ≥48px tap target
- Keyboard: focus moves to live timeline input when step 3 becomes active

## What This Page Must NOT Do

- No improvisation prompts — runbook steps are predefined, Ayaat follows them
- No contradictory comms (single template, single language toggle)
- No "auto-resolve" — every entry is human-authored
- No penalty if elapsed >5min — soft reminder, no blame
- No public sharing of timeline (private to admin + provider + owner)
