# 4.1 · Spec — Admin Queue Dashboard

> Ayaat's daily entry point. Sorted by urgency — acute events at top, in-stay at bottom — so she always knows what to handle next. Operating ceiling banner is always visible at the top.

## URL & Routing

- **Route:** `/admin/queue` · SSR · deep-linkable · Ayaat's `/admin` root
- **Auth gate:** `admin` role required · redirects to `/admin/sign-in` if missing
- **Polling:** every 30s for queue state changes (acute events are time-critical)
- **Push:** subscribe to `admin.queue.acute` and `admin.queue.disputes` channels · sound alert on new acute event

## Design Sections

**D1. Header** — admin name + Eid-week context + logout

**D2. Operating ceiling banner (sticky top)** — `{success-soft}` default · color shifts with state · 3-axis indicator (providers / in-stay / acute events)

**D3. Tab bar** — Queue (default) · Providers · Payouts · Runbook · Settings

**D4. Queue sections** — 6 priority-ordered sections · expandable/collapsible · bulk view for low-priority sections

**D5. Card per item** — priority indicator · subject · key entities · time-elapsed · CTA · reuses `{queue-row}` pattern (DESIGN.md)

## On-Page State Machine

- **State 1 (default — quiet):** Banner green · sections all expanded · acute card absent · disputes card absent
- **State 2 (acute-event-active — current):** Acute section expanded · timeline-entry CTA prominent on acute card · sections 2-6 still visible
- **State 3 (ceiling-near):** Banner turns orange at 22/70 (88% of any axis) · throttle-new-supply suggestion appears
- **State 4 (ceiling-breached):** Banner turns red · throttle-new-supply CTA primary · escalation banner: "Multi-admin RBAC recommended · reach out to platform team"
- **State 5 (high-volume-period):** Bulk view auto-collapses lower-priority sections · "12 review-moderation items" links to 4.7
- **State 6 (new-acute-trigger):** Sound alert + push notification · acute card slides in from top · timeline-entry CTA focuses

## Accessibility

- Header: `<header>` semantic · admin context
- Ceiling banner: `<aside role="status" aria-live="polite">` announces axis state changes
- Tab bar: `role="tablist"` · arrow-key navigation · `aria-selected` reflects active tab
- Queue sections: `<section>` semantic with `<h2>` headers · `aria-expanded` on accordion
- Priority dots: `aria-label="Priority: Acute"` · not just color
- Cards: `<article>` semantic · CTA is the primary focusable element
- Bulk-view toggle: keyboard-operable · `aria-expanded` reflects state
- New-acute-trigger: `role="alert"` announces arrival · sound is secondary signal
- All CTAs ≥48px tap target

## What This Page Must NOT Do

- No drag-to-reorder queue sections (priority order is system-determined)
- No hiding acute events behind pagination (always at top, always expanded)
- No "mark all read" without action (Ayaat must handle each item)
- No removing items from queue without resolution (audit trail)
- No auto-dismissal of disputes (Brief §3: independent dispute flow)
