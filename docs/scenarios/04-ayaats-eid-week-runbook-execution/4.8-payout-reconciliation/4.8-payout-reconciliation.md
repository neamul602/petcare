# 4.8 — Payout Reconciliation View

## Overview

**Page Purpose:** Ayaat reconciles MFS settlements against provider payouts — monthly finance close.

**Exit Action:** Mark period reconciled · export to accounting.

## Page Composition

### Reconciliation table
- Date · provider · gross · commission · net · MFS settlement ref · payout status
- Discrepancy detection (settlement vs. expected)

### Filters
- By provider · by date range · by payout state

### Monthly close
- Total gross · total commission · total net · expected MFS balance
- Mismatch flag if any

## State Variations

- **All-matched**: Clean state
- **Mismatch-detected**: Inline flag · investigation CTA
- **Period-closing**: Bulk action to mark all current-period payouts reconciled
