# 3.2 · Spec — Date-Level Capacity Calendar

> Per-date capacity control. Rashid's intentional setting is the source of truth — no auto-adjust. The calendar IS the operating picture.

## URL & Routing

- **Route:** `/provider/calendar` · SSR for desktop, SPA-hydrated for mobile
- **Default view:** current month · Eid-month if currently in Eid-week
- **Prefetch:** peak-window definitions pre-loaded (Eid · December · summer)

## Design Sections

**D1. Header** — back to dashboard · month/year display · peak-window banner if applicable

**D2. Month grid** — 7-column calendar · each cell shows date number + capacity number · peak-window cells use `{capacity-cell.peak}` style · tap → opens per-date editor

**D3. Per-date editor (sheet/modal)** — `{card.elevated}` · sticky bottom on mobile, side-panel on desktop
- Total capacity input (number stepper)
- Per-species breakdown (dogs/cats) — sums must equal total
- Free-text notes (e.g. "Quiet week — limited capacity")
- Reset-to-baseline + Save CTAs

**D4. Peak-window controls** (in editor footer)
- "Expand for Eid-week" preset · copies current week to Eid-week dates
- "Reset to baseline after peak" · bulk reverts

## On-Page State Machine

- **State 1 (default — current month):** Eid-month pre-loaded if currently Eid · cells show capacity · peak dates tagged
- **State 2 (Eid-week active):** Peak banner prominent · expanded capacity visible across Eid-week dates
- **State 3 (December peak approaching):** Banner "December peak in 4 weeks · adjust capacity now" · cells for December highlight
- **State 4 (capacity-conflict detected):** System warns if current bookings > set capacity · inline banner · cell turns `{destructive-soft}` · cannot save new lower number until bookings resolved
- **State 5 (sync-with-baseline):** Bulk action confirms · all dates reset to default · success toast
- **State 6 (per-date editor open):** Editor sheet open · capacity input focused · Cancel/Reset/Save visible

## Accessibility

- Calendar grid: native `<table>` with `<caption>` (Eid-week peak window) · `<thead>` with day names · date cells are `<button>` with `aria-label="Aug 25, 5 spots total, Eid-peak window"`
- Peak indicator: `aria-label="Eid peak window"` on relevant cells
- Editor sheet: `<dialog>` native · focus trap when open · Escape closes
- Capacity steppers: `aria-valuenow/min/max` reflecting current state
- Per-species inputs: `aria-describedby` linking to "Total capacity" hint
- Conflict warning: `role="alert"` announces blocking condition
- Bulk confirm: `role="alertdialog"` for sync-baseline confirmation
- Keyboard: arrow-key navigation between date cells · Enter opens editor · Esc closes

## What This Page Must NOT Do

- No on/off toggle (Brief §6 explicit: date-level capacity, not toggle)
- No auto-adjust based on bookings (Rashid's intentional setting is the source of truth)
- No lower-number save when bookings already exceed capacity (conflict block)
- No comparison to other providers ("Tier-A providers set capacity ~4-5 on average")
- No pressure CTAs ("Lock in your Eid capacity now — demand is high")
