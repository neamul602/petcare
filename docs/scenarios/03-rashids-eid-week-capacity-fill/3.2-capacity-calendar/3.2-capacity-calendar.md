# 3.2 — Date-Level Capacity Calendar

## Overview

**Page Purpose:** Give Rashid per-date control over capacity — set capacity for known peaks (Eid, December, summer), adjust for unexpected demand, see utilization at a glance.

**Exit Action:** Tap a date → inline editor (capacity number + per-species breakdown).

## Page Composition

### Calendar grid (month view, default Eid-month)
- Each cell shows: date · capacity · booked · available
- Eid-week cells highlighted with peak-window tag
- Tap any date to edit

### Per-date editor
- Total capacity (number)
- Per-species breakdown: dogs / cats
- Notes (e.g. "Quiet week — limited capacity")

### Peak-window controls
- "Expand capacity for Eid-week" preset
- "Reset to baseline after peak"

## State Variations

- **Eid-peak active**: Eid-week dates show expanded capacity (5 vs typical 3)
- **December-peak approaching**: Banner "December peak in 4 weeks · adjust capacity now"
- **Capacity-conflict detected**: System warns if current bookings exceed capacity
- **Sync-with-baseline**: Bulk action to revert all dates to default

## What This Page Must NOT Do
- No on/off toggle (the brief is explicit: date-level capacity, not on/off — Brief §6)
- No auto-adjust based on bookings (Rashid's intentional setting is the source of truth)
