# 3.1 — Provider Dashboard (Bookings + Capacity)

## Overview

**Page Purpose:** Show Rashid his full Eid-week operational picture at a glance — pending requests, confirmed bookings, in-stay, payouts, demonstrated-Fit stats — so he can manage the compressed week without dropping balls.

**Entry Context:** Rashid opens the PetCare PWA from his phone at home. Lands directly on the Provider dashboard.

**Exit Action:** Tap any pending request → next page (3.3 — Incoming Booking Request); or tap any in-stay card → 3.5 — In-Stay Management.

**On-Page Interactions:**
- Tap pending-request cards → 3.3
- Tap in-stay cards → 3.5
- Tap "Calendar" tab → 3.2 — Capacity Calendar
- Tap "Payouts" tab → 3.10
- Tap "My profile" tab → 3.8

## Page Composition

### Header
- **Provider name + Tier-A badge (gold)**
- **Quick stats:** "Eid-week utilization: 95% · Pending: 4 · In-stay: 6 · Payouts this month: BDT 84,000"

### Tabs
1. **Today** (default) — pending requests + in-stay
2. **Calendar** — 3.2
3. **Payouts** — 3.10
4. **My profile** — 3.8

### Pending requests (top section)
- Each card: pet thumbnail + pet name + species + care-config tags (diabetic · insulin · special diet) + dates + "Confirm / Decline" CTA
- Sorted by submission time · countdown for confirmation-window

### In-stay bookings
- Each card: pet thumbnail + name + check-in date + days remaining + daily-update status (✓ posted / ⏳ due today) + "Open" CTA

### Capacity bar
- Eid-week visual: 5/5 spots filled tonight · 4/5 tomorrow · 5/5 day after · peak-window tag visible

### Footer
- **Care-record stat:** "Diabetic small dogs handled successfully: 13" (climbed from 12 this week)

## State Variations

- **Peak-window active** (Eid): Banner "Eid-week capacity expanded · peak-window terms active"
- **Quiet week** (off-peak): Banner "Off-peak · consider running a re-engagement nudge to past owners (Admin can suggest)"
- **Acute event active**: Banner "1 acute event active · open Runbook"
- **Capacity near full**: Banner "3 of 5 spots filled for tomorrow's window"
