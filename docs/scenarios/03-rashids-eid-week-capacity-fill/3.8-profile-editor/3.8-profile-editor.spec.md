# 3.8 · Spec — Provider Profile Editor

> Where Rashid shapes the public-facing profile. Photos, services, capability flags, prior-experience statement — and the live preview that shows him what's missing. **Capability flags don't override demonstrated-Fit — Fit accumulates from bookings.**

## URL & Routing

- **Route:** `/provider/profile/edit` · desktop-primary layout (side-by-side editor + preview) · mobile collapses preview into a tab/sheet
- **Autosave:** debounced 1.5s · explicit "Save changes" CTA at bottom for discrete saves
- **Profile-completeness:** computed from a backend endpoint · updates live as fields change

## Design Sections

**D1. Header** — back to 3.1 · "Profile editor · {completeness}% complete" · completeness shown prominently

**D2. Profile-completeness indicator** — visual progress ring + textual "X% complete · Add: 2 more photos, 1 prior-experience detail"

**D3. Editor sections** (left, 60% on desktop / full-width on mobile) — 6 collapsible sections:
- **Photos** (hero + 5 gallery) — at least 3 required · 5 recommended
- **Services** (boarding / walking / grooming) — price per night / walk / stay
- **Capacity** (per-species · per-size if dogs)
- **Capability flags** (multi-select · 5 options)
- **Vet affiliation** (optional · linked displays on profile)
- **Prior-experience statement** (free-text · 500 char max · char counter)

**D4. Live preview** (right, 40% on desktop / sheet on mobile) — public-facing profile view · same layout as 1.4 Provider Profile · updates live as fields change

**D5. Sticky Action Bar** — `{sticky-action-bar}` variant · Discard changes (link) + Save changes (primary)

## On-Page State Machine

- **State 1 (default — Tier-A first-time-setup):** Wizard-style · each section explained · completeness low (~50%) · Save enabled
- **State 2 (Tier-A returning user):** All sections pre-filled · completeness indicator shows what's missing · Save enabled
- **State 3 (completeness-low):** Inline reminder "Profiles at 80%+ get 2x more confirmed bookings" · informational, no penalty
- **State 4 (admin-requested-update):** Inline banner "PetCare Admin requests: please add 2 more recent photos" · `{info-soft}`
- **State 5 (unsaved-changes):** Discard enabled · warning when leaving page · Save persists
- **State 6 (preview-open on mobile):** Bottom sheet with profile preview · tap outside closes

## Accessibility

- Header: `<header>` semantic · completeness `aria-label="Profile completeness: 85 percent"`
- Each section: `<details>` / `<summary>` native · expanded state preserved per visit
- Photos: drag-and-drop with keyboard alternative (file picker) · each photo has `<button>` with remove `aria-label="Remove photo {N}"`
- Capability flags: `role="checkbox" aria-checked` per chip
- Prior-experience: `aria-describedby` linking to char count
- Live preview: `aria-live="polite"` announces changes
- Discard modal: `role="alertdialog"` · confirms unsaved-changes discard
- Save button: `aria-disabled="true"` if no changes to save
- All inputs have visible labels · no placeholder-only labels
- All CTAs ≥48px tap target

## What This Page Must NOT Do

- No capability flags overriding demonstrated-Fit (Fit accumulates from bookings, not declarations)
- No auto-decline for low-completeness profiles (this is informational)
- No fake reviews / photos / completions (prohibited)
- No comparison to other providers in editor
- No pressure CTAs ("Complete your profile now to boost rankings")
