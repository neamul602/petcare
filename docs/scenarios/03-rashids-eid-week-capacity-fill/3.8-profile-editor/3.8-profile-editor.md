# 3.8 — Provider Profile Editor

## Overview

**Page Purpose:** Let Rashid update the public-facing profile (photos, services, capability flags, prior-experience statement) — and show him what's missing at a glance via the profile-completeness indicator.

**Exit Action:** Tap "Save changes" → returns to 3.1 with updated profile.

## Page Composition

### Profile-completeness indicator
- "85% complete · Add: 2 more photos, 1 prior-experience detail"
- Visible at top so Rashid sees what's missing

### Sections
1. **Photos** (hero + 5 gallery) — at least 3 required · 5 recommended
2. **Services** — boarding / walking / grooming add-ons · price per night
3. **Capacity** — per-species (dogs / cats) · per-size if dogs (small/medium/large)
4. **Capability flags** — species accepted · special care accepted · senior pets accepted · diabetic · high-anxiety
5. **Vet affiliation** — optional · if linked, displays on profile
6. **Prior-experience statement** — free-text · 500 char

### Preview
- Live preview of public profile on the right (desktop) or via "Preview" CTA (mobile)

## State Variations

- **First-time-setup**: Wizard flow with each section explained
- **Tier-A anchor**: Admin can request updates · inline "PetCare Admin requests..." banner
- **Profile-completeness-low**: Inline reminder · "Profiles at 80%+ get 2x more confirmed bookings"

## What This Page Must NOT Do
- No capability flags overriding demonstrated-Fit (Fit accumulates from bookings, not from declarations)
