# 3.10 · Spec — Payouts + Earnings

> Predictable cadence, no surprises. Every booking's payout state visible. The structural answer to Rashid Want #1 (predictable payouts) — and the last beat before Scenario 03's climax.

## URL & Routing

- **Route:** `/provider/payouts` · desktop-primary layout (table) · mobile collapses to cards
- **Polling:** every 5min for payout state changes · push subscription on payout-channel
- **Payout cycle:** bi-weekly · backend computes next payout date

## Design Sections

**D1. Header** — back to 3.1 · "Payouts · {Month} {Year}" · static

**D2. This-month summary** — 4-column stat block · `{card.muted}` per metric
- Gross earnings · commission (with rate) · net payout · cadence (with next date)

**D3. Per-booking payout table** — `{card.elevated}` desktop · collapses to cards on mobile
- Columns: Booking · Gross · Commission · Net · Status · Released date
- Status: ✓ Released · ⏳ Pending · ❄ Frozen · ⚠ On hold

**D4. Frozen payouts banner** — `{destructive-soft}` if any payouts on hold · explainer + Admin link

**D5. Reconciliation view** — MFS settlement timeline · static informational

## On-Page State Machine

- **State 1 (default — all payouts released):** Clean state · no frozen banner · table shows release dates
- **State 2 (dispute-window-open):** Frozen banner visible · payout row shows "On hold" status · Admin link in banner
- **State 3 (acute-event-active):** Payout may be extended pending post-mortem · banner "Payout extended pending post-mortem"
- **State 4 (payout-cycle-mismatch):** Banner "MFS settlement typically takes 1-2 business days · patience appreciated" · `{info-soft}`
- **State 5 (mobile collapsed):** Table converts to card list · each row becomes a `{card.muted}` · tap to expand details

## Accessibility

- Summary block: `<dl>` semantic · each metric is `<dt>`/`<dd>` · full context in `aria-label` (e.g., "Net payout: BDT 71,400")
- Payout table: native `<table>` · `<caption>` "Payouts for August 2026" · `<thead>` with column headers · `<tbody>` with rows
- Each row: tap target wraps entire row · `aria-label="Tito Eid stay, gross BDT 19,800, net BDT 16,830, released Sep 3"`
- Status chips: `aria-label="Status: Released"` · not just visual
- Frozen banner: `role="alert"` announces hold condition · Admin link is keyboard-accessible
- Reconciliation: static informational content · `role="note"` for SR context
- Mobile card collapse: native `<details>` / `<summary>` per row · expanded state preserved
- All numbers `tabular-nums` for visual stability
- All CTAs ≥48px tap target

## What This Page Must NOT Do

- No payout-rate negotiation (Tier-A introductory 15% is fixed in v1)
- No manual payout release (bi-weekly cadence is system-driven)
- No hiding frozen payouts (transparency is the trust signal)
- No comparison to other providers' earnings
- No pressure CTAs ("Boost your tier for better rates!" — no tier-rate differential in v1)
