# 3.6 — Daily Update Composer

## Overview

**Page Purpose:** Let Rashid post a daily update (photo + structured note) for Tito in under 60 seconds — the update accumulates into Care History and (for the demonstrated-Fit band) into Rashid's profile.

**Exit Action:** Tap "Post update" → returns to 3.5 with the new update visible.

## Page Composition

### Photo upload zone
- 1 photo minimum, 4 max · 5MB each
- Camera or gallery
- Optional caption per photo

### Structured note fields (the care-record template)
- **Insulin:** Given at 8am ✓ (toggle: given / skipped / partial)
- **Kibble portion:** Measured · ½ cup at 8am + ½ cup at 8pm (free-text)
- **Behaviour:** Calm · Active · Anxious · (multi-toggle)
- **Any concerns:** None ✓ · (free-text if any)
- **Glucose observation:** Normal · Slight drop · Slight rise · Concerning (radio)

### Voice-input
- Bangla + English voice-to-text for the free-text "any concerns" field

### Preview
- Shows what Bibi will see on her in-stay view

### Footer
- **Primary CTA:** "Post update"
- **Helper:** "Takes 30 seconds · helps Bibi stay informed · builds your demonstrated-Fit profile"

## State Variations

- **Default**: Photo + structured fields empty
- **Photo-required**: CTA disabled until photo uploaded
- **Concerning-glucose-flagged**: When "Concerning" is selected, an inline prompt suggests the acute-event runbook trigger (without forcing it)

## What This Page Must NOT Do

- No auto-fill from past updates (authenticity matters)
- No scheduling updates in advance (the soft-enforcement only works if updates are real-time)
- No forcing structured fields beyond photo + behaviour tag (the rest is optional)
