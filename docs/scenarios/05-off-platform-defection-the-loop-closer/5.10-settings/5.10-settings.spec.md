# 5.10 · Spec — Settings / Profile (Per Role)

> Per-role settings — language toggle (FR-47 Bangla-first), identity verification, notification preferences, account management. Each role sees only what matters to them; cross-role fields (language, identity verification) appear consistently.

## URL & Routing

- **Route:** `/{role}/settings` · deep-linkable from avatar menu and footer
- **Auth gate:** role-appropriate
- **Polling:** static (settings are user-controlled)

## On-Page State Machine

- **State 1 (default — current):** All sections visible · language set to user's preference
- **State 2 (identity-edit):** Inline form · phone/NID/email editable · save/cancel
- **State 3 (language-toggle):** Re-renders entire UI on language change · confirmation toast
- **State 4 (notification-channel-toggled):** Channel toggle on/off · confirmation toast
- **State 5 (notification-type-toggled):** Per-type toggle · confirmation toast · except acute-event (locked)
- **State 6 (delete-account-modal):** Modal · "This is irreversible · contact support first · we'll verify by phone before deletion"
- **State 7 (soft-delete-pet):** Pet soft-deleted · removed from active lists · preserved in history · audit log entry

## Accessibility

- Header: `<header>` semantic · sections `<section>` semantic
- Identity card: `<dl>` semantic · verified status `aria-label="Verified"`
- Language: `<fieldset>` with `<legend>` · radio group
- Notifications: `<fieldset>` per section · toggles `role="switch" aria-checked`
- Acute-event toggle: `aria-disabled="true"` · `aria-describedby` explains
- Account management: delete CTA `aria-describedby` warns irreversibility
- All CTAs ≥48px tap target (mobile) / 40px (desktop)

## What This Page Must NOT Do

- No disabling acute-event alerts (always on)
- No re-engagement nudge frequency above 1 per booking per 60 days
- No language change without confirmation toast
- No account deletion without contact-support-first modal
- No revealing other users' settings
- No comparison to other platforms
- No marketing pressure ("Enable notifications to never miss a booking!")
