# 5.3 — Issue Report ("Report an Issue")

## Overview

**Page Purpose:** Independent dispute trigger within the dispute window — freezes provider payout; does NOT retroactively affect reviews.

**Exit Action:** Submit report → routes to Ayaat's queue (4.6) · payout frozen.

## Page Composition

### Issue category (taxonomy)
- Medication mishandled · food not followed · injury during stay · behavior / care quality · safety concern · other

### Description (free-text)
- Photos / evidence (optional)

### Dispute-window countdown
- "You can report an issue until [date] · [N] days remaining"

### Outcome expectations
- "PetCare will investigate · provider payout frozen until resolved · independent of any review you leave"

## State Variations
- **Within-window**: Submit enabled
- **Outside-window**: Submit disabled · "Dispute window expired · leave a review instead"
- **Already-reported**: "Your report is being investigated by Admin"
