# 5.3 · Spec — Issue Report

> Independent dispute trigger within the dispute window. **Brief §3 enforced:** freezes provider payout · does NOT retroactively affect reviews · review can still be left even after dispute submitted.

## URL & Routing

- **Route:** `/owner/stays/:bookingId/report` · deep-linkable from 5.1 "Report an issue" CTA and 5.2 Step 1 "No" radio
- **Auth gate:** `owner` role · must own the referenced booking
- **Window:** 7 days from booking completion · countdown shown
- **Polling:** every 60s for window expiry state

## On-Page State Machine

- **State 1 (within-window — current):** Window countdown green · all fields enabled · Submit active when valid
- **State 2 (near-window):** Window countdown orange · "prioritize" hint · same form enabled
- **State 3 (last-day):** Window countdown red · "escalate" hint · same form enabled
- **State 4 (window-expired):** All fields disabled · "Dispute window expired · leave a review instead" · review CTA routes to 5.2
- **State 5 (already-reported):** All fields replaced by "Your report is being investigated by Admin" · view-status CTA
- **State 6 (submit-pending):** Submit disabled · spinner · "Submitting your report..."
- **State 7 (submit-success):** Confirmation · "Report submitted · admin will respond within 48 hours" · route to dashboard

## Accessibility

- Header: `<header>` semantic · countdown `aria-label="{N} days remaining"`
- Window countdown: `role="status" aria-live="polite"` announces expiry
- Issue category: `<fieldset>` with `<legend>` · radio group · arrow-key navigable
- Description: `<label for>` · `aria-required="true"` · char-count `aria-describedby`
- Photos: `<input type="file" accept="image/*,application/pdf">` · `aria-describedby`
- Independent notice: `role="note"` · `aria-label="Reminder: reviews and disputes are independent records"`
- Submit CTA: `aria-disabled="true"` until valid · `aria-describedby` explains
- All CTAs ≥48px tap target

## What This Page Must NOT Do

- No removing reviews because of dispute (Brief §3 independence)
- No submitting without category (required)
- No submitting without description (required, min 30 chars)
- No auto-resolution (every report is admin-reviewed)
- No public visibility of dispute report
- No penalty on provider until Ayaat resolves (frozen payout, not penalized)
- No comparison to other disputes ("similar cases resolved this way")
