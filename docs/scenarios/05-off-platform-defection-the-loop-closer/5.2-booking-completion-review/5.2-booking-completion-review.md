# 5.2 — Booking Completion Confirmation (Owner Reviews)

## Overview

**Page Purpose:** Owner confirms completion + leaves verified review with photos from the actual stay — the demonstrated-Fit accumulator that surfaces to the next owner on first search.

**Exit Action:** Submit review → returns to dashboard · Skip review (allowed but reminded).

## Page Composition

### Completion confirmation
- "Was the stay completed as expected?" · Yes / No · if No → routes to 5.3 Issue Report

### Verified review form
- Star rating (1–5) · text · photos from actual stay (1+ required)
- Review gate: only after booking completion

## State Variations
- **Just-completed**: Default form · photos required
- **Skip-review**: Reminder · "Reviews with photos are how the next owner finds the right provider"
