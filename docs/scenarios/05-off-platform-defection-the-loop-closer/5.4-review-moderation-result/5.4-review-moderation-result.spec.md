# 5.4 · Spec — Review Moderation Result View

> Transparency in the moderation process. Owner sees admin's outcome — what was edited, what was removed, why, and the appeal mechanism. **SM-C3 enforced:** critical reviews protected unless policy violation documented.

## URL & Routing

- **Route:** `/owner/reviews/:reviewId/moderation` · deep-linkable from review-moderation push notification and from care-history view
- **Auth gate:** `owner` role · must own the referenced review
- **Polling:** static once moderation completes (read-only result)

## On-Page State Machine

- **State 1 (approved — default):** No outcome banner · original review shown as published · no appeal needed
- **State 2 (edited):** Warning banner · original shown with edited version beneath · appeal CTA visible
- **State 3 (removed):** Destructive banner · original review still visible (transparency) · reason + audit trail · appeal CTA primary
- **State 4 (appeal-submitted):** Appeal status visible · "Your appeal is being reviewed by a different admin"
- **State 5 (appeal-upheld):** "Appeal upheld · review restored" · if removed: re-published · if edited: full version restored
- **State 6 (appeal-denied):** "Appeal denied · decision stands" · final-decision language · no further appeal

## Accessibility

- Header: `<header>` semantic · audit ID `<dl>` semantic
- Outcome banner: `role="status"` for edited / `role="alert"` for removed
- Original review: `<article>` semantic · read-only
- Moderation detail: `<section>` · `<dl>` semantic for key-value pairs
- Reason category: read-only · `aria-label="Reason category"`
- Audit trail: `<section>` semantic · audit ID as `<code>` for copy-to-clipboard
- Appeal CTA: `aria-label="Submit appeal for this moderation decision"`
- All CTAs ≥48px tap target

## What This Page Must NOT Do

- No removing the original review text (transparency — even removed reviews remain visible here)
- No hiding the moderation reason (full disclosure required)
- No appeal-blocking language ("final decision, no exceptions")
- No comparison to other moderated reviews ("similar decisions elsewhere")
- No penalty on owner for appealing
- No public visibility of this page (owner + admin only)
