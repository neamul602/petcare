# 5.12 — Empty States (Cross-Cutting)

## Overview

**Page Purpose:** Friendly empty states when content hasn't accumulated yet — no bookings, no reviews, no in-stay updates, no applications.

## Page Composition

### Empty state templates

**No bookings yet (Owner dashboard):**
- "No bookings yet · Find care near you"
- Illustration + CTA

**No reviews yet (Provider profile):**
- "No verified reviews yet · See [provider's] demonstrated-Fit evidence above"
- (Alternative: provider's Tier-A anchor evidence)

**No in-stay updates yet (In-stay view):**
- "Today's update is pending · provider typically posts by [time]"
- Soft expectation language (not blame)

**No applications yet (Admin provider review):**
- "No Tier-B applications this week"

**No past bookings (Care history view):**
- "No past bookings yet · Tito's first stay will appear here"
