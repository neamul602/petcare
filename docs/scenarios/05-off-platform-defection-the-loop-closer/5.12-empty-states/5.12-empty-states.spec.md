# 5.12 · Spec — Empty States (Cross-Cutting)

> Friendly empty states when content hasn't accumulated yet. **Brand voice:** empowering, organic — not "you're missing out." Each state surfaces a real next action.

## URL & Routing

- **Routes:** all empty states appear inline on the relevant page (no dedicated route)
- **Auth gate:** varies per empty state
- **Polling:** static once displayed

## Design Sections

**D1. Header** — back · "{state-name}" · menu trigger

**D2. Empty illustration** — `{card.elevated}` · organic illustration

**D3. Empty title + body** — title · explanation · next-action CTA

## Empty State Templates

### No Bookings Yet (Owner Dashboard)
- **Title:** No bookings yet
- **Body:** Find care near you — your first verified booking starts the care history that travels with your pet.
- **CTA:** Find care near you (primary)

### No Verified Reviews Yet (Provider Profile)
- **Title:** No verified reviews yet
- **Body:** See {provider}'s demonstrated-Fit evidence above — verified care-record stats and Tier-A badge signal trusted care for {species}.
- **CTA:** View demonstrated-Fit (primary) · Tier-A fallback if applicable

### No In-Stay Updates Yet (5.1 In-Stay View)
- **Title:** Today's update is pending
- **Body:** Provider typically posts by {time}. We'll let you know when it arrives.
- **CTA:** No CTA needed (passive wait) · "Open chat" secondary

### No Applications Yet (Admin Provider Review)
- **Title:** No Tier-B applications this week
- **Body:** 2 Tier-A outreach invitations queued. Pace is healthy at the 1/25/75 ceiling.
- **CTA:** View Tier-A outreach queue (primary)

### No Past Bookings (2.1 Care History View)
- **Title:** No past bookings yet
- **Body:** {pet}'s first stay will appear here once it's complete. The verified review and care history will travel with them.
- **CTA:** Find care near you (primary)

### No Notifications (5.5 Inbox)
- **Title:** No notifications
- **Body:** We'll let you know when something happens.
- **CTA:** No CTA needed (passive wait)

### No Daily Updates Yet (3.5 In-Stay Management)
- **Title:** No updates posted yet today
- **Body:** {provider}'s daily update cadence is established — first update typically arrives by 9pm.
- **CTA:** Add reminder (primary) · Open chat (secondary)

## On-Page State Machine

- **State 1 (no-bookings):** Owner-dashboard variant · "Find care near you" CTA
- **State 2 (no-reviews):** Provider-profile variant · Fit-anchor narrative · CTA to demonstrated-Fit
- **State 3 (no-in-stay-updates):** In-stay variant · soft expectation · no CTA or chat
- **State 4 (no-applications):** Admin variant · pacing narrative · CTA to outreach queue
- **State 5 (no-past-bookings):** Care-history variant · forward-looking · CTA
- **State 6 (no-notifications):** Inbox variant · passive · no CTA
- **State 7 (no-daily-updates-yet):** In-stay-management variant · reminder CTA

## Accessibility

- Header: `<header>` semantic · empty state `role="status"` (informational)
- Empty title: `<h1>` semantic · illustration has `aria-label="{title}"`
- Empty body: empowering language · no shame attribution
- CTAs: keyboard-navigable · `aria-describedby` explains action
- All CTAs ≥48px tap target

## What This Page Must NOT Do

- No shame attribution ("You haven't booked yet — get started!")
- No urgency-bait ("Last chance to find care for Eid!")
- No corporate-feeling illustrations
- No comparison to other users
- No "missing out" framing
- No more than 1 primary CTA per empty state
- No forcing action when a passive wait is appropriate (in-stay updates, notifications)
