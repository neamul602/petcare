# 5.13 — Loading / Skeleton States (Cross-Cutting)

## Overview

**Page Purpose:** Skeleton states for surfaces where data is loading — shortlist, calendar, queue dashboard, care-history. No spinner-only states; skeletons preserve layout shape.

## Page Composition

### Skeleton templates per surface

**Curated shortlist (1.3):**
- 4 card skeletons at the same height as real cards
- Photo block · text lines · CTA block

**Capacity calendar (3.2):**
- Month-grid cells with date numbers + capacity placeholders

**Admin queue dashboard (4.1):**
- Section blocks with priority indicator + card placeholders

**Care-history view (2.1):**
- Pet card + section blocks + booking-card skeletons

### Helper text
- "Loading..." (never "Please wait..." — brand voice)
- Estimated time hint for slow connections (Brief §5 risk #14)
