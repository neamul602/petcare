# 5.8 — Defection Detection Dashboard (Admin)

## Overview

**Page Purpose:** Ayaat sees soft signals of off-platform defection BEFORE the moat starts dissolving — surfaces owner-side and provider-side patterns.

**Exit Action:** Tap a pattern → intervention playbook (FR-36 + FR-48).

## Page Composition

### Soft-signal categories
- **Owner-side:** Repeat-booking-rate drop · care-history viewed but no booking · unbookmarked
- **Provider-side:** Utilization drop · accepted fewer bookings · profile views but no conversions
- **Cross-side:** Owner-provider pair appeared together once but no second booking

### Pattern detection
- "12 owners with care-history ≥ 1 booking have not re-booked in 60+ days" · intervention CTA

### Intervention playbook
- Owner re-engagement nudge · provider re-engagement offer · both through PetCare

## State Variations
- **No-patterns**: Clean state
- **Patterns-detected**: Inline cards with intervention suggestions
