# 5.11 · Spec — Error States (Cross-Cutting)

> Failure modes that don't break the linear sunshine path. Capacity-exhausted, confirmation-timeout, payment-failed, dispute-window-expired, network-fail, load-shedding. **Brand voice: no blame-shifting language · solution-forward.**

## URL & Routing

- **Routes:** all error states appear inline on the relevant page (no dedicated route) · deep-linkable to retry action
- **Auth gate:** varies per error state
- **Polling:** retry-capable states poll every 30s for resolution

## Design Sections

**D1. Header** — back · page title · menu trigger

**D2. Error illustration** — `{card.elevated}` · simple illustration · severity color

**D3. Error title + body** — title · explanation (no blame) · solution-forward CTAs

**D4. Action CTAs** — 1-2 actions · primary + secondary · no panic language

## Error State Templates

### Capacity Exhausted (1.3 / 1.6)
- **Title:** ⚠ No providers have full availability for these dates
- **Body:** Two options — try widening dates · view full approved catalog
- **CTAs:** Try widening dates (primary) · View full catalog (secondary)
- **Illustration:** empty calendar with date highlighted

### Confirmation Timeout (1.8)
- **Title:** ⏱ Provider didn't respond in time
- **Body:** Your authorization hold was released. You can find another provider or adjust your dates.
- **CTAs:** Find another provider (primary) · Adjust dates (secondary)
- **Illustration:** hourglass · no blame

### Payment Failed (1.7)
- **Title:** ⚠ Payment authorization failed
- **Body:** Try another payment method or save as draft.
- **CTAs:** Try another payment method (primary) · Save as draft (secondary)
- **Illustration:** card with subtle X · not alarming

### Dispute Window Expired (5.3)
- **Title:** ⏱ Dispute window expired
- **Body:** You can still leave a verified review — that's how the next owner with your pet's specific care needs finds the right provider.
- **CTAs:** Leave a review (primary) · Back to stay (secondary)
- **Illustration:** calendar with crossed-out date

### Network Fail
- **Title:** 📡 Connection is slow
- **Body:** Showing cached results from {time}. You can retry or save offline.
- **CTAs:** Retry (primary) · Save offline (secondary)
- **Illustration:** signal-bars at low strength

### Load-shedding (Peak Eid)
- **Title:** ⏱ SMS may take 30–60s
- **Body:** We're in low-signal areas right now. Auto-retry is on. You can also enter the code manually when it arrives.
- **CTAs:** Auto-retry (primary) · Manual code entry (secondary)
- **Illustration:** clock with patience indicator

## On-Page State Machine

- **State 1 (capacity-exhausted):** Empty-state illustration · 2 CTAs · routes to 1.3 with widened dates or 1.6 with full catalog
- **State 2 (confirmation-timeout):** Hourglass illustration · 2 CTAs · authorization released · back to shortlist
- **State 3 (payment-failed):** Card illustration · 2 CTAs · try another method or save draft
- **State 4 (dispute-window-expired):** Calendar illustration · "Leave a review" primary CTA · routes to 5.2
- **State 5 (network-fail):** Signal-bars illustration · retry + save-offline CTAs · cached timestamp visible
- **State 6 (load-shedding):** Clock illustration · auto-retry + manual-code-entry CTAs
- **State 7 (retry-success):** Re-attempting · spinner · transitions to relevant success state
- **State 8 (retry-failed):** Same error · "Still happening? Contact support +880-XXX-XXXX" · support CTA

## Accessibility

- Header: `<header>` semantic · error state `role="status"` (retryable) / `role="alert"` (terminal)
- Error title: `<h1>` semantic · illustration has `aria-label="{title}"`
- Error body: solution-forward language · no blame attribution
- CTAs: keyboard-navigable · `aria-describedby` explains retry/save behavior
- Manual code input: `<label for>` · `aria-describedby` connects to format hint
- Cached timestamp: `aria-label="Showing cached results from {time}"`
- All CTAs ≥48px tap target

## What This Page Must NOT Do

- No blame-shifting language ("Your network is too slow")
- No corporate-feeling illustrations (human, simple)
- No urgency-bait ("Retry now or lose your booking!")
- No comparison to other platforms
- No hidden errors — every state has a clear path forward
- No panic language ("Critical error" · "Disaster" · "Failed")
- No more than 2 CTAs per error state (avoid decision paralysis)
