# 1.7 · Spec — Booking Submission + Payment Authorization

> The commit moment. Payment is held (not captured) until provider confirms. Plain language — never confuse "authorize" and "charge."

## URL & Routing

- **Route:** `/book/[providerSlug]/review` · state: query mirrors 1.6 form-state
- **Payment gateway:** bKash · Nagad · Stripe (card) · SDKs loaded inline on first need
- **Submission:** POST `/bookings` with `authorization_hold_id` from gateway

## Design Sections

**D1. Header** — back nav → 1.6 with form preserved

**D2. Review sections (D2-D8)** — one card per care dimension · each has section title + summary + Edit link (returns to 1.6 focused on that section)

**D9. Price breakdown** — itemised table · tabular-nums for all currency · "Platform fee · included" not a number
- Total line: h3 styled with foreground + font-semibold

**D10. Payment method picker** — 3-option radio (bKash default) · sub-form switches below

**D11. Payment sub-forms (dynamic)**
- bKash: phone input + bKash OTP step (handled inside SDK modal)
- Nagad: analogous
- Card: full Stripe Elements form

**D12. Authorization language callout** — `{info-soft}` background · radius-md · p-4 · readable copy — explicitly distinguishes "authorize" vs "charge"

**D13. Cancellation policy** — collapsible · link expands full copy

**D14. Primary CTA + secondary** — sticky CTA submits · "Save as draft" persists form state

## On-Page State Machine

States preserved. Spec adds:
- **Default review:** payment method default bKash · sub-form visible · CTA enabled
- **Submitting (State 2):** CTA disabled · spinner · countdown timer starts (30s timeout) · spinner replaced with progress bar
- **Authorization-success:** route to 1.8 · holds the auth_id · server will mirror payment hold
- **Authorization-fail (State 3):** inline error below sub-form · CTA re-enabled · "Try another payment method" link to switch radio
- **Gateway-timeout (State 4):** inline message + retry CTA · "Save as draft" preserves state
- **Save-as-draft:** form state serialized to localStorage · dashboard shows the draft

## Accessibility

- Edit links: each section labeled clearly · keyboard focus order follows visual order
- Radio group: native `<fieldset><legend>Payment method</legend>` · checked item visually + programmatically
- Authorization callout: `<aside role="note" aria-labelledby="auth-callout-title">` so SR announces intent on focus
- Total line: `aria-label="Total authorization hold: BDT 19,800"`
- Submit button: `aria-disabled="true"` during State 2 · `aria-busy="true"` while gateway call in flight
- Error states: `role="alert"` linked via `aria-describedby` on failed input
