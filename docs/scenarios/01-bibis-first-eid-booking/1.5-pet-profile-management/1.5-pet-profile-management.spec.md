# 1.5 · Spec — Pet Profile Management (Tito's First Profile)

> Captures Tito's care profile. This is the data that pre-fills Scenario 02's climax. Save = seed the moat's compounding structure.

## URL & Routing

- **Route:** `/pets/new` (create) · `/pets/[petId]/edit` (edit)
- **Auth:** sign-in required · cookie-gate · redirect to 1.2 if not signed in
- **Persistence:** `pc_pet_profiles` (collection per owner) · denormalized into booking record on save

## Design Sections

**D1. Header** — back nav (returns to 1.4 · discarding changes prompts confirm)

**D2. Helper text** — explains the persistence value (this is the moat seed explanation)

**D3. Identity block** — pet name + photo upload zone (`{card.muted}` · 80×80 photo thumb · 1 photo min, 5 max)
- Photo thumb: radius-md · aspect-square · tap opens full editor · "Add photos" CTA below

**D4. Basic info block** — structured fields · species locked from shortlist filter

**D5. Behaviour block** — radio groups + multi-toggle chips + free-text triggers

**D6. Medical conditions block** — coral-section-header (the special-care marker) · condition cards
- Each condition: severity radio · vet contact fields (required if Moderate+) · notes textarea
- "Add another" CTA appends a row

**D7. Medication block** — medication cards · name + dose + frequency + route + notes
- Mirrors condition rows but field-set is medication-specific

**D8. Diet block** — radio groups + brand autocomplete + schedule text + treats textarea + allergies multi-toggle

**D9. Special-attention block** — 3 textareas (anxiety / comfort / exercise)

**D10. Sticky CTA** — `{button.primary, size.lg}` · "Save Tito's profile & continue" · secondary "Save as draft"

## On-Page State Machine

States preserved. Spec adds:
- **Default empty:** all sections open · Save disabled · inline "Required" hints next to required fields
- **Required-field warning:** scroll-to-first-error on Save tap · `aria-invalid="true"` + `role="alert"` on error message
- **Photo-required:** Save disabled · hint below photo zone "Add at least 1 photo"
- **Severity=Moderate+:** vet contact fields animate in · if empty on Save, inline error
- **Multi-pet:** pet selector at top of D3 · "Add another pet" CTA below identity block
- **Returning-user + existing pet:** form pre-fills from saved profile · "Edit" link toggles to view-only · "Book again" path opens (Scenario 02 hook — different route)
- **Save→loading:** button disabled + spinner · 1-2s typical · on success → 1.6 · on network-fail → "Saved as draft · try again when connected"

## Accessibility

- Section headers: `<button aria-expanded>` · chevron icon `aria-hidden`
- Photo upload: `<input type="file" accept="image/*" capture="environment">` with visible button styling
- Radio groups: `<fieldset><legend>` · each option native `<input type="radio">`
- Multi-toggle chips: `<button role="checkbox" aria-checked>` · keyboard Space toggle
- Condition/medication remove: `<button aria-label="Remove [condition name]">`
- Form errors: `aria-describedby` links input to error message · `role="alert"`
- Counter on treats textarea: `aria-live="polite" aria-atomic="true"`
- Tab order: section-by-section top-to-bottom · skip-link "Skip to save button" for long form
