# 1.6 · Spec — Booking Configuration

> Stay-specific care config. Pre-filled from Tito's profile (D3-D7 mirror 1.5). Stays-specific overrides only.

## URL & Routing

- **Route:** `/book/[providerSlug]/configure` · query: `petId` (default = last-saved pet for owner), `start`, `end`
- **State held in:** URL query (durable) + form-state (in-memory, lost on refresh — preserve prompt)
- **Capacity:** re-checked on every date change (FR-12)

## Design Sections

**D1. Stay-dates card** — `{card.muted}` · radius-lg · date range as text + edit link + availability pill

**D2. Pet card** — `{card.flat}` · photo thumb · summary line · edit link → 1.5

**D3. Food section** — toggle `Use Tito's saved food` (default ON) · when ON: read-only card view · when OFF: editable fields

**D4. Medication section** — same pattern as D3

**D5. Additional services** — checkbox list · each line: checkbox + service name + price · total line updates live

**D6. Special instructions** — textarea + char counter + voice-input mic icon · pre-filled from profile caretaking notes (if any)

**D7. Emergency contact** — two read-only lines (vet + backup)

**D8. Price summary (sticky bottom)** — itemised table · platform-fee = included (no number) · total big · helper · primary CTA · secondary "Save as draft"

## On-Page State Machine

States preserved. Spec adds:
- **Default pre-filled:** all D3-D4 toggles ON · D5 medication-admin pre-checked (FR-16: included for medical cases)
- **Capacity-conflict:** top banner replaces D1 entirely when capacity fails · banner: "Rashid's availability has changed since you opened this booking — please adjust dates or [choose another provider]" · CTA disabled · choose-another-link → /search with filters preserved
- **Date-edited:** debounced 500ms · re-query capacity via FR-12 · update availability pill · if now-invalid, capacity-conflict banner
- **Toggle OFF:** expand animation (200ms) · fields become editable · validate-on-blur
- **Free-text > 800:** counter amber · save disabled > 1000
- **Returning-user Scenario 02:** separate route via dashboard "Book again" · this page is stay-specific. Scenario 02's pre-fill happens at the redirect level, not in this page.

## Accessibility

- Toggle: `<button role="switch" aria-checked>` with hidden text label
- Checkboxes: native `<input type="checkbox">` · associated `<label>` wraps row
- Live region for services total: `aria-live="polite"` announces updates to screen reader
- Char counter: `aria-live="polite"` · `aria-atomic="true"`
- Capacity conflict banner: `role="alert"` · focus moves to it on appearance
- Vet contact phone: `href="tel:+880..."` · opens dialer on mobile
- Form labels: visible above field (preferred over floating labels — care fields deserve clarity)
