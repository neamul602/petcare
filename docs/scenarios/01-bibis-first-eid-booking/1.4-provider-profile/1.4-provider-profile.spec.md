# 1.4 · Spec — Provider Profile — Public

> The conversion surface from shortlist tap to booking intent. Demonstrated-Fit is the deciding signal.

## URL & Routing

- **Route:** `/providers/[slug]` where slug = e.g. `rashid-gulshan-tier-a`
- **SEO:** SSR-able · Open Graph with provider photo + Tier-A badge title
- **Auth:** anonymous view OK · "Save for later" requires sign-in (cookie-gated)

## Design Sections

**D1. Header** — back nav (returns to 1.3)

**D2. Gallery** — hero image · 16:9 aspect · radius-md · pagination dots · tap opens lightbox
- Lightbox: full-screen overlay (`{elevation.xl}`) · swipe between photos · close on backdrop

**D3. Identity block** — name + tier-a-badge · neighborhood · quick stats · availability pill

**D4. Demonstrated-Fit section** — h3 + subtitle + horizontal scrollable fit-cards · each card:
- `{card.muted}` background · radius-lg · p-4 · min-w-[160px]
- Number prominent (editorial serif 28px) · unit below (text-sm muted-fg)
- Tap → filtered reviews list anchored to that fit

**D5. Verified Reviews** — h3 + filter chips + 3 expanded review-cards + see-all CTA
- Each review card: `{review-card.*}` pattern (photo grid 4:3 · rating chip · quote in editorial serif)

**D6. Care setup details** — list of structured fields with descriptive bullets · no free-text

**D7. Pricing** — primary price line + modal-opener breakdown link

**D8. Response time + reassurance** — text-xs muted

**D9. Sticky bottom bar** — `{card.elevated}` style with shadow · price summary + primary CTA `Book this provider`

## On-Page State Machine

States preserved. Spec adds:
- **Default:** SSR-rendered with skeleton-free first paint · photo lazy-loaded below 16:9 fold if connection slow
- **Capacity-just-changed:** WebSocket or 30s polling diff. Inline banner updates status pill color (forest→amber→red) with text. Sticky CTA disables + shows "Please choose another date or provider" if now unavailable.
- **No reviews yet:** D5 replaced with "No verified reviews yet — see Rashid's demonstrated-Fit evidence above" · review-filter chips hide
- **Profile incomplete:** small line under stats "Profile completeness: 70% · See what's missing" · does NOT block booking
- **Returning customer:** "You've booked Rashid before" above tier badge + "Book again" pre-filled path (Scenario 02 hook)
- **Save for later (signed in):** heart fills accent · stays on page
- **Save for later (anonymous):** heart tap → modal "Sign in to save providers"

## Accessibility

- Hero image: `alt="Provider facility photo — Rashid's Gulshan home, dedicated pet room visible"`
- Gallery has `aria-roledescription="carousel"` · `aria-label="Provider photos"`
- Tier-A badge: `aria-label="Tier-A provider, personally vetted by PetCare"`
- Fit cards: `<button>` semantic · `aria-describedby` linking the number unit ("12 diabetic small dogs handled successfully")
- Sticky CTA: `aria-label="Book Rashid Gulshan Tier-A for BDT 19,800 total"` so screen readers announce summary
- Lightbox: focus trap · Escape closes · `role="dialog"`
- Photos in review: empty `alt=""` for decorative duplicate thumbnails
- Tap targets ≥48px (sticky CTA = 56px)
