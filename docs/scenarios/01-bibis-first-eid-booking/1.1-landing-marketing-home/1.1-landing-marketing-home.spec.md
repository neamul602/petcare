## Design Sections (numbered, build order)

**D1. NavBar** — sticky top · `bg-background` · 56px height · logo left, language toggle + sign-in right
- Logo: wordmark "PetCare" in editorial serif (Source Serif 4, 600) · 18px
- Language toggle: pill toggle (EN | বাংলা) · 32px height · persists to cookie
- "Sign in" link: button-ghost size-sm · ghost foreground hover

**D2. HeroSection** — `bg-background` (cream-50) · padding-y `space-y-16` (top 80, bottom 80)
- Headline: h1-editorial · {typography.scale.5xl} mobile / {typography.scale.6xl} tablet+
- Subhead: body-relaxed (16/1.65) · max-w-2xl · muted-foreground (stone-600)
- CTA group: button-lg primary "Find care near me" + link-secondary "How PetCare works"
- Trust strip: 3 chips (forest pill ghost variant with check icon)

**D3. SpecialCareSection** — `bg-muted` (cream-100) · full-bleed · cards in 1-col mobile / 3-col tablet+
- Section h2: editorial 2xl · mb-4 · "For special-care pets"
- 3-up: insulin · allergies · anxiety · each card muted-bg · radius-lg · p-6
- **What this page must NOT do:** any clinical-care claim — keep informational

**D4. VerifiedReviewsStrip** — `bg-background` · padding-y `space-y-12`
- Section h2: editorial · "From real Dhaka stays"
- 3 cards horizontally scrollable · verified-review-card pattern · photo 4:3 · rating chip · quote (editorial)
- CTAs: "See all reviews" link at section end (routes to reviews page, not in this scenario)

**D5. HowItWorksSection** — muted-100 bg · numbered step list
- 1, 2, 3 in forest-green filled circles (40px) · labels "Search" · "Confirm" · "Stay + Review"

**D6. ProviderCTASection** — `bg-background` · single-line banner with arrow link
- "For Providers: apply to join PetCare →" — text-base · primary color · links to /apply

**D7. Footer** — muted-100 · 4-col grid mobile stack / 4-col desktop
- Col 1: trust line ("PetCare is not a veterinary boarding service…")
- Col 2: language toggle persistent + About
- Col 3: Pre-launch supply assessment link · Customer support
- Col 4: Legal — Animal Welfare Act · Data Protection draft · Trade license

## On-Page State Machine

States from upstream outline preserved. Spec adds wireframe-level behavior:
- **State 2 (permission prompt):** OS-level browser prompt on tap, not a custom modal — `navigator.geolocation.requestPermission`. If granted, router navigates to 1.2 with `?location=geo`. If denied, 1.2 with `?location=manual`.
- **State 3 (HowItWorksModal):** XL dialog (elevation.xl) · max-w-md · centered · tap backdrop dismisses · no scroll lock trap (closes on Esc + backdrop tap).

## Accessibility (NFR-12 · WCAG 2.1 AA)

- Hero h1 contrast vs background: foreground charcoal-900 on cream-50 = 16.2:1 ✓
- Primary CTA focus ring: `{elevation.ring}` on focus-visible · never silently dropped
- Tap targets ≥44px (button-lg = 48px) ✓
- Section semantic HTML: `<header>` · `<main>` · `<section aria-labelledby>` · `<footer>`
- Trust strip uses `aria-label="Trust signals"` since it's text-only icons
- Image alt: review photos use `alt="Verified review photo from Gulshan stay"` (no PII)
- Page lang attribute set from cookie or browser default (`<html lang="bn">` default per Bangla-first)
