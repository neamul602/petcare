## Design Sections

**D1. Top bar** — back arrow + page title "Search"

**D2. Filter bar (sticky)** — search summary chip + horizontal filter chips + result count + sort
- Summary chip: `{badge.neutral}` pill · tap opens filter modal
- Filter chips: pill toggles · selected = `{primary-soft bg + primary-soft-fg text}`
- Sort selector: ghost button-size-sm · "Tier-A first" default · dropdown

**D3. Shortlist** — 4 provider cards · vertical scroll · each:
- `card-elevated` variant (`{card.elevated}`)
- Hero photo: 4:3 aspect · radius-md · object-cover
- Provider name: text-xl font-semibold · 1 line · truncate
- Tier-A badge: `{tier-a-badge}` positioned next to name · inline
- Neighborhood + distance: text-sm muted-fg · map-pin icon (lucide)
- Availability status: pill `{booking-state.captured}` with dot indicator
- Rating row: star icon · rating tabular-nums · review count
- Demonstrated-Fit section: header + 3-4 fit-cards (compact · check icon)
- Price line: text-base font-medium · tabular-nums
- Primary CTA: `{button.primary, size.md}` · "Book this provider →"
- **Card tap target:** entire card → 1.4

**D4. Full-catalog CTA** — separator + link "View all 14 approved providers" + helper

## On-Page State Machine

States from upstream outline preserved. Spec adds:
- **State 1 default:** Shortlist loads with `data-result-count="4"` · first paint uses skeleton cards (same height, shimmer) · replace on data
- **State 2 (filter modal):** Modal slides up (`{elevation.xl}`) · sticky header + scrollable body + sticky footer with "Apply" CTA · state held in URL query · page state restored from URL on back-nav
- **Capacity-changed-mid-search:** poll every 30s · diff against state · if changed, subtle inline refresh with banner "Rashid updated availability · still available for your dates" or "1 provider no longer matches"
- **Network-fail:** cached results banner with "Connection slow — showing cached results from 2 min ago · [Retry]"

## Accessibility

- Filter chips: `role="button"` · `aria-pressed` for toggle state · keyboard-operable (Space)
- Cards: `<article>` · `<a>` wrapping the whole card → focus ring `{elevation.ring}`
- Fit cards: `role="button"` · `aria-label` describes the proven claim ("12 diabetic small dogs handled successfully — see verified reviews")
- Rating: star icon has `aria-label="4.9 stars"` (numeric not visible to screen readers is wrong if hidden — keep rating visible)
- Image alt: `alt="Provider facility photo — Gulshan home-sitter"` (no PII)
- Skeleton loaders: `role="status" aria-label="Loading providers"` · replaced with real content with no flash
- Sort selector: `<select>` native · stays keyboard-friendly
