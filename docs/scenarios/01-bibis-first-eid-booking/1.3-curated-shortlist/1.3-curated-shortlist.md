# 1.3 — Curated 3–5 Shortlist

## Page Metadata

| Property | Value |
|---|---|
| **Scenario** | 01 — Bibi's First Eid Booking with Tito |
| **Page Number** | 1.3 |
| **Platform** | Mobile (PWA, mid-range Android) |

## Overview

**Page Purpose:** Deliver the curated 3–5 providers ranked by demonstrated-Fit for Tito's diabetic Shih Tzu care over the Eid window — fast enough that Bibi's first-search confidence lands in seconds, not minutes.

**Entry Context:** Bibi just completed OTP sign-in on 1.2 with `location=banani` and `dates=eid-default` (Eid-1 → Eid+9). The page opens directly to the shortlist with these filters applied.

**Exit Action:** Tap a provider card → next page (1.4 — Provider Profile).

**On-Page Interactions:**
- Tap any provider card → opens that provider's profile (1.4)
- Tap "View all approved providers" (secondary action, below the shortlist) → full-catalog view with full filter UI
- Tap filter chips at top (Species · Date · Price · Special-care flag) — modal opens to refine
- Tap "Save this search" — saves search criteria to her dashboard for later
- Scroll past shortlist → "View all approved providers" CTA appears

## Inherited User Situation + Mental State (carried forward)
- **Hope:** Top of the shortlist is the right Tier-A Gulshan home-sitter with diabetic-small-dog demonstrated-Fit signals *visible before she taps*.
- **Worry:** The shortlist shows generic "we accept dogs" cards with no demonstrated-Fit evidence — another Facebook-Marketplace-shaped list she has to grind through.

## Page Composition

### Filter bar (sticky top)
- **Search summary chip:** "Banani · Dog · Eid-1 → Eid+9 · 9 nights" — tap to edit
- **Filter chips:** Species (Dog ✓) · Dates (9 nights ✓) · Special care (Medication · Daily routine) · Sort (Default = Tier-A first · Demonstrated-Fit first)
- **Result count:** "4 providers match your search"

### Shortlist (3–5 cards, ranked)
For each card:
- **Provider photo (real, taken at their facility or home)** — not a stock image
- **Provider name + Tier-A badge (gold) or Tier-B badge (silver)**
- **Neighborhood + distance from Banani** ("Gulshan · 2.4 km")
- **Capacity availability for the requested dates** — green dot "Available all 9 nights"
- **Price per night** ("BDT 2,200 / night · 9 nights = BDT 19,800")
- **Star rating (avg) + photo count** ("4.9 ★ · 47 reviews with photos")
- **Demonstrated-Fit band** (the differentiator): "Handled 12 diabetic small dogs successfully · 6 cat boardings · 4 repeat owners"
- **Self-declared capability fallback** (only if no demonstrated-Fit yet): "Accepts: dogs · senior pets · medication · special diet"
- **Tap target:** entire card opens profile (1.4)

### Below the shortlist (secondary)
- **CTA:** "View all 14 approved providers in Banani & nearby" — the brief's "View all approved providers" secondary action (FR-13)
- **Helper text:** "We've shown you 4 providers most likely to be a great match. See the full approved catalog if you want to compare more."

### Empty / edge state
- **Zero results:** "No providers in Banani have full availability for your dates. Try widening dates, or [see full approved catalog]."
- **Capacity-exhausted warning:** If Bibi's dates would fail any shortlisted provider on date-level capacity, those providers are removed at submission-time, not at confirmation (FR-12) — so this list is pre-validated

---

## State Variations

| State | Trigger | Behavior |
|---|---|---|
| **Default** | Page load with pre-filled filters | 4 providers shown · Tier-A Gulshan at top |
| **Filter-modified** | User changes dates / species / special-care | Re-query · shortlist updates · result count updates |
| **Full-catalog** | Tap "View all 14 approved providers" | Opens full list with sort UI · Tier-A pinned top · pagination |
| **Empty** | Zero providers match (e.g. exotic species) | Friendly empty state + full-catalog link |
| **Capacity-changed-mid-search** | Provider toggles capacity while Bibi is on page | Subtle inline refresh · no full page reload |
| **Loading** | Initial query | Skeleton cards (same height as real cards) · no spinner-only states |
| **Network-fail** | Slow connection | "Connection slow — showing cached results from 2 min ago" banner + retry |

---

## What This Page Must NOT Do

- **No paid placement** — Tier-A rank is earned, not bought (Brief §3 — never ordered by paid placement; FR-11)
- **No star-rating-only ranking** — average star rating is NOT optimized per Brief §4 (SM-C3 explicit counter-metric)
- **No "Sponsored" or "Boosted" labels** — even soft ones; the curated-trust promise dies the moment paid placement enters
- **No results that bypass the date-level capacity check** — exhausted capacity is filtered out at submission, not at confirmation (FR-12)
- **No more than 5 results in the default shortlist** — 3–5 is the brief's explicit number (FR-11)
- **No urgency-bait** — no "Only 2 spots left!" or "Book before someone else does!" — brand voice is empowering, not pressure-driven (TM Handover open item #5)
