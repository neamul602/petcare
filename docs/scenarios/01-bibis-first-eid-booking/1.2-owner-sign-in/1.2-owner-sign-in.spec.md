# 1.2 · Spec — Owner Sign-In (Phone OTP)

> Verification + neighborhood capture. Single-screen flow on mobile — no scroll.

## URL & Routing

- **Route:** `/sign-in` · accepts query `?location=geo|manual|<neighborhood>`
- **Cookie:** `pc_locale` (lang) · `pc_session` (returning user)
- **Hydration:** on returning user, skip OTP and route straight to 1.3

## Design Sections

**D1. Top bar** — back arrow (24px) · aria-label "Back to landing" · focus ring (forest)

**D2. Title block** — h2 editorial 24px · sub line in Bangla (Noto Serif Bengali) · 14px muted

**D3. Phone block** — country-code prefix `+880` (32px left rail) · number input right of prefix · format `017XX-XXXXXX` as user types · helper text below

**D4. Neighborhood block** — label · select input · 7 options (Gulshan · Banani · Baridhara · Dhanmondi · Uttara · Mirpur DOHS · Other Dhaka) · default = query param or first option

**D5. Primary CTA** — button-lg primary · 56px height · full-width · disabled (40% opacity) when phone not 10 digits

**D6. Fallback actions** — "Use email instead" (link-secondary) · "Resend code" (60s disabled countdown) — both 14px muted

**D7. Consent line** — 12px muted-foreground · 1px border-top separator · legal text

**D8. (Post-OTP) Name field** — text input · label "What should providers call you?" · auto-fill from OTP profile if available

## On-Page State Machine

States from upstream outline preserved. Spec adds:
- **State 2 (OTP-sent):** detect Android SMS Retriever API; auto-fill via `if (window.OTPCredential)` — manual paste fallback always available · countdown timer driven by `useInterval` (1s)
- **State 3 (OTP-error):** red border on all 6 boxes · inline error below · no cooldown penalty · preserve entered values, clear them after 1 error
- **State 5 (Returning user):** on `pc_session` cookie present, fire silent refresh; on success, route to 1.3; on refresh-fail, fall to OTP flow
- **Network-fail:** SMS-gateway timeout (60s) → inline error with copy "SMS may take 30–60s in low-signal areas" · CTA changes to "Type the code I received" (resumes manual entry) · no toast spam

## Accessibility

- Phone input: `inputmode="numeric"` · `autocomplete="tel-national"` · `aria-describedby` linked to helper
- OTP boxes: each `aria-label="Digit N of 6"` · group `role="group" aria-label="One-time password"` · `inputmode="numeric"` on all
- Countdown: `aria-live="polite"` announces "Resend available" at 0
- Errors: `role="alert"` on inline error · `aria-invalid="true"` on inputs in error state
- Color contrast: charcoal-900 on cream-50 ✓; muted-foreground on cream-50 = 5.1:1 ✓
- All CTAs ≥48px tall · tap targets ≥44px (button-lg meets)
